  <action>
Create storage.rules at the project root (same level as firestore.rules).

The rules must:
1. Default-deny everything (no public access).
2. Allow a user to read and write only files under their own UID path.
3. For the resumes path specifically: enforce a 5 MB file size limit on writes (per CONCERNS.md).

The Firebase Storage path convention for this app (inferred from Firestore user-scoped pattern users/{uid}/...): files are stored under /{uid}/... in the storage bucket.

Write the rules file with this exact structure:

  rules_version = '2';
  service firebase.storage {
    match /b/{bucket}/o {
      // Default deny
      match /{allPaths=**} {
        allow read, write: if false;
      }

      // User-scoped files: only the owner can read or write
      match /{uid}/{allPaths=**} {
        allow read: if request.auth != null && request.auth.uid == uid;
        allow write: if request.auth != null && request.auth.uid == uid;
      }

      // Resumes: enforce 5 MB upload limit
      match /{uid}/resumes/{fileName} {
        allow read: if request.auth != null && request.auth.uid == uid;
        allow write: if request.auth != null
                     && request.auth.uid == uid
                     && request.resource.size <= 5 * 1024 * 1024;
      }
    }
  }

Note: The more specific /resumes/ rule takes precedence over the broader /{uid}/{allPaths=**} rule for resume uploads, enforcing the size cap. The broad rule still covers all other file types under the user's UID without a size cap.

If the app stores files at a different path prefix (e.g., users/{uid}/resumes/{fileName}), the rules must match that path. Since no storage upload code was found to confirm the exact path, use the /{uid}/... convention which matches the Firestore user-scoped pattern and is consistent with Firebase Storage defaults. Add a comment: // Update path prefix if files are stored under a different root.

Do NOT deploy the rules in this plan — deployment requires firebase CLI authentication which is a human action. The file is created for manual deployment or CI deployment. Add a comment at the top:
  // Deploy with: firebase deploy --only storage
  // Or via Firebase Console: Storage > Rules
  </action>
