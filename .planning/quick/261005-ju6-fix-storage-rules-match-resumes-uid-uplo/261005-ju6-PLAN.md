Remove the stale "Update path prefix" line and replace with a note that resumes live at resumes/{uid}/ and logos at {uid}/companies/{companyId}/logo. Inside `match /b/{bucket}/o`:
1. Keep `match /{allPaths=**} { allow read, write: if false; }` as explicit default deny.

3. Add `match /resumes/{uid}/{fileName}`: `allow read, delete: if request.auth != null && request.auth.uid == uid;` and `allow create, update: if request.auth != null && request.auth.uid == uid && request.resource.size <= 5 * 1024 * 1024 && request.resource.contentType.matches('application/pdf');`
4. Add `match /{uid}/companies/{companyId}/logo`: `allow read, delete` same owner check; `allow create, update` owner check && `request.resource.size <= 2 * 1024 * 1024` && `request.resource.contentType.matches('image/.*')`.
Do not use `write` on the capped blocks (would break delete since request.resource is null). Do not touch client code. Content-type check is lenient to what the UI accepts (PDF only for resumes, image/* for logos); note in a comment that a file with empty File.type would be rejected, which is acceptable because the picker filters by accept.
